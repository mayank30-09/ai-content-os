# Support & Community Guide

Thank you for using AI Content OS! We offer community-driven support channels as well as options for enterprise guidance.

---

## 💬 Community Support Channels

### 1. GitHub Discussions (Recommended)
For general questions, architecture discussions, feature ideas, or sharing how you use AI Content OS:
👉 [Join GitHub Discussions](https://github.com/mayank30-09/ai-content-os/discussions)

- **Q&A**: Ask questions about worker integration, workflow templates, or deployment.
- **Show and Tell**: Share custom workers or workflow extensions you've built.
- **Ideas**: Propose feature enhancements for future phases.

### 2. GitHub Issue Tracker
For bug reports, unexpected errors, or verified technical defects:
👉 [Report an Issue](https://github.com/mayank30-09/ai-content-os/issues)

Before opening a new issue:
- Check existing open/closed issues to avoid duplicates.
- Run `uv run pytest` to confirm system state.
- Provide full diagnostic logs from Loguru (`user_data/logs/`).

---
