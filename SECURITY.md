# Security Policy

AI Content OS takes security seriously. We encourage responsible disclosure of vulnerabilities to ensure the protection of our users and enterprise deployments.

---

## 🛡️ Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported |
| :--- | :--- |
| `v0.8.x` (Latest) | ✅ Yes |
| `< v0.8.0` | ❌ No |

---

## 🔒 Reporting a Vulnerability

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report vulnerabilities directly to our security maintainers:

- **Email**: `security@contentos.ai` (or open a private GitHub Security Advisory)
- **Encryption Key**: PGP Key fingerprint `4A12 B89C DE34 5678` (optional)

### What to Include in Your Report

Please include as much detail as possible to help us triage and resolve the issue quickly:

1. **Type of issue**: (e.g., credential leak, SSRF, arbitrary code execution, SQL injection).
2. **Steps to reproduce**: Minimal code snippet or step-by-step instructions.
3. **Potential impact**: Who or what is affected.
4. **Suggested fix**: (Optional) Patch or mitigation recommendations.

---

## ⏱️ Response SLA

- **Acknowledgment**: Within 48 hours.
- **Initial Assessment**: Within 5 business days.
- **Patch Release**: High severity vulnerabilities will be patched within 14 business days.
